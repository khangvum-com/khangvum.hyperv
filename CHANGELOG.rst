====================================================
``khangvum.hyperv`` Ansible Collection Release Notes
====================================================

.. contents:: Topics

v1.0.0
======

New Modules
-----------
- ``khangvum.hyperv.hard_disk`` - Attach, detach, or relocate VHD/VHDX disks.
- ``khangvum.hyperv.host`` - Configure host-level default storage paths and global settings.
- ``khangvum.hyperv.hv_host_info`` - Gather system facts and hypervisor status.
- ``khangvum.hyperv.network_adapter`` - Configure virtual network adapters and VLAN settings.
- ``khangvum.hyperv.vm`` - Provision and manage Hyper-V virtual machines.
- ``khangvum.hyperv.vm_automatic_action`` - Manage VM automatic start/stop behaviors.
- ``khangvum.hyperv.vswitch`` - Manage Hyper-V virtual switches.
